DesktopMate for Windows

Run DesktopMate.exe. Keep the _internal folder beside the executable.
Python is included; no separate Python installation is required.
The setup dialog appears first. Verify your Gemini API key, choose a
conversation model, then click the start button to show the desktop character.
If verification fails, correct the key or connection and retry in the dialog.
Internet is required for the existing online 3D libraries and Gemini AI.
Settings are saved under %APPDATA%\vrm_desktop_helper and are not included
in the package. Model listing verifies the key and supported generation method;
actual generation remains subject to the account's permissions and quota.
